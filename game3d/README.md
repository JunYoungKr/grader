# Centipede Express — 3D 코어 물리 프로토타입 (v0.2)

기획서(`Centipede Express v0.1`)의 **3.1 "한 몸, 여러 뇌" 조종 구조**를
**3D**로 검증하는 브라우저 그레이박스입니다. 2D 버전(`../game/`)에서 확인한
코어 루프(연결 마디 + 봇 협력 + 화물 물리)를 Three.js + cannon-es로 옮겼습니다.

> 기획서 10.2가 지목한 최대 리스크 — "연결된 지네를 여럿이 조종하는 게 웃긴가" —
> 를 Unity 없이 눈으로 확인하는 것이 목적입니다.

## 실행

빌드/설치 불필요. 정적 파일이라 브라우저로 바로 엽니다.

```bash
# 방법 1: 파일 직접 열기
open game3d/index.html            # macOS
xdg-open game3d/index.html        # Linux

# 방법 2: 로컬 서버(권장)
cd game3d && python3 -m http.server 8080   # → http://localhost:8080
```

Three.js 0.169 + cannon-es 0.20을 `vendor/libs.js`로 **로컬 번들**(esbuild IIFE)
했기에 오프라인에서도 동작합니다.

## 조작

| 동작 | P1 | P2 (P로 켜기) |
|---|---|---|
| 이동 | `W` `A` `S` `D` | `↑` `←` `↓` `→` |
| 점프 | `Space` | `Enter` |
| 그립(앵커·브레이크) | `L-Shift` | `R-Shift` |
| 웅크리기(저자세 브레이크) | `Q` | `.` |

기타: `1`~`8` P1 마디 · `[` `]` P2 마디 · `+`/`-` 지네 길이(2~8) · `R` 리셋 ·
`C` 화물 재배치 · `B` 자동주행 데모 · `X` 자가충돌 토글 · `H` 도움말

**코스**: 계단을 오르고 → 낭떠러지를 달려 점프하고 → 좁은 외나무 다리를 건너 →
깃발까지. 옆이나 아래로 떨어지면 즉시 재배송(기획서 4.1 "짧은 실패, 빠른 재도전").

## 지금 구현된 것 (코어 물리만)

- **연결된 N개 마디(2~8)**: ConeTwist 관절(꺾임/비틀림 제한)로 이어져 서로를 당김
- **마디별 독립 조작** + **봇 마디**(가까운 사람 입력 협력 추종, 막힘·틈새·단차 자동 점프)
- **공용 액션 3종**: 점프 / 웅크리기 / 그립(접지 중에만 발동, 마디를 앵커로 고정 — 낭떠러지 지탱)
- **시너지 게이지**: 마디 속도 벡터 정렬도에 비례해 이동 속도 0.6~1.6배
- **화물 물리**: 등 위에 얹혀 기울기·점프 충격에 날아감. **화물량은 마디 수에 비례**(기획 6장). 유지 수 실시간 HUD
- **3D 지형**: 계단·낭떠러지 점프·외나무 다리(옆 낙하 리스크)·도착 깃발
- **아트 방향성**(기획서 9장): 로우폴리 + 파스텔, 동글동글 마디·큰 눈·더듬이·
  속도 비례로 파닥이는 다리 3쌍, 그림자

## 물리 구현 노트 (Unity 이전 시 참고)

- **cannon-es 마찰은 신뢰하지 말 것**: 마찰 상한이 사실상 스텝당 임펄스로 작용해
  물리값보다 수십 배 강했다(μ=0.02에서도 5m/s 슬라이드가 0.2초에 정지함을 실측).
  → 마디-지면 마찰 0 + **속도 조향(velocity steering)** + 무입력 시 능동 브레이크로 해결.
  화물-마디 마찰(1.2)은 별도 ContactMaterial이라 등짐 접착은 유지.
- **관절 장력은 살아있다**: 조향은 스텝당 `accel·dt`만큼만 속도를 끌어당기므로,
  관절이 매 스텝 속도를 재분배해 "서로 당기는 몸" 긴장이 유지된다.
- **그립 앵커는 KINEMATIC**: type만 STATIC으로 바꾸면 mass가 남아 관절 임펄스가
  velocity에 누적(유령 속도)되고 해제 순간 무명령 발사가 난다. KINEMATIC은
  invMassSolve=0이라 원천 차단되고 지형 접촉도 유지된다. 그립은 얼린 body를 기억해
  마디 전환·P2 OFF·자동주행 등 라우팅 변화에도 반드시 해제된다.
- ConeTwist(swing 1.1rad / twist 0.6rad) + 인접 마디 충돌 제외(`collideConnected: false`),
  비인접 마디는 충돌(X로 토글).
- 느낌 튜닝은 `centipede3d.js` 상단 `CFG`: `moveSpeed`·`accel`·`jumpV`·`joint.swing/twist`·
  `botFollow`·`synergyMin/Max` 등.
