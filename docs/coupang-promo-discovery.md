# 살림 상품 후보 수집

기존 오전 9시 상품 갱신 작업이 성공하면 골드박스와 살림 검색어에서 상품 후보를 이어서 수집한다. 기존 상품 목록이 먼저 저장되며 후보 수집 실패는 그 목록을 되돌리지 않는다. 관리자는 `/admin/discovery`에서 수동으로 다시 수집할 수도 있다.

## 후보의 의미

골드박스 출처는 쿠팡 파트너스 골드박스 API에서 받은 상품이라는 뜻이다. API 응답에는 할인 전 가격, 할인율, 쿠폰 조건이 없다. 골드박스 출처만으로 최저가나 할인율을 주장하지 않는다.

검색 출처는 정해 둔 살림 문제를 검색한 결과다. 쿠팡 검색 결과에 광고 상품이 포함될 수 있다. 검색어와 상품명이 관련 있는 후보만 보이도록 거르지만, 검토 전에는 추천이나 사용 후기라고 표시하지 않는다.

현재 검색 주제는 서랍 칸막이, 냉장고 회전 트레이, 싱크대 틈새 선반, 욕실 청소 브러시, 접이식 빨래 바구니다. 주제와 상품명 조건은 `src/lib/coupang-promo.ts`에서 변경한다.

## 검토 순서

1. `새 후보`에서 상품 사진과 이름, 출처를 살핀다.
2. `현재 상품 확인`을 눌러 선택된 판매 옵션과 실제 결제 조건을 확인한다.
3. 가치가 있으면 `관심 상품으로 저장`을 누른다. 맞지 않으면 `제외`한다.
4. 이미지나 게시글을 제작하기 전에 가격을 다시 확인한다. 사이트에 제휴 링크를 넣으면 제휴 고지도 함께 표시한다.

같은 상품과 옵션을 다시 수집할 때 이전 조회 가격을 보관한다. 관리 화면은 이전 조회 가격만 보여준다. 이는 평소 가격이나 최저가를 뜻하지 않는다. 저장과 제외 상태는 다음 수집 후에도 유지된다.

## 운영 확인

마이그레이션 `20260927000300_coupang_promo_candidates.sql`을 적용한다. 로컬에서 수동 수집하려면 `npm run sync:promo`를 실행한다. 필요한 환경변수는 쿠팡 키 두 개, Supabase URL과 서비스 키다. 성공 후 관리자 페이지의 최근 수집 시각과 후보 수를 확인한다.

후보는 서비스 키만 조회할 수 있는 별도 테이블에 저장된다. 일반 방문자에게 후보나 검토 상태를 공개하지 않는다.
