# Grader 유입 및 구매 전환 실행 계획

작성일: 2026-09-27

## 목표와 범위

주부 고객이 생활, 주방 제품을 고를 때 겪는 질문으로 방문해, 자기 집의 조건을 확인하고, 필요한 제품의 판매처로 이동하도록 만든다. 최종 성과는 제휴사의 실제 주문과 확정 수수료로 판단하고, 사이트의 제휴 링크 클릭은 그에 앞선 행동으로 측정한다.

이번 문서는 구현 전 실행 계획이다. 일정은 착수 후 약 4주의 초기 운영 주기를 가정한다. 자료 확보, 외부 계정 접근, 검색 반영 속도에 따라 달라지며, 4주 안에 검색 순위나 매출 상승을 보장하는 일정은 아니다.

계획 단계에서 실제 방문, 주문 보고서는 조회하지 않았다. 현재 구매율, 채널별 효과, 개선 폭은 미확정이다. 전환율 목표는 측정을 검증하고 기준 데이터를 확보한 뒤 정한다.

## 현재 작업과의 연결

- SEO 변경은 PR #8로 원격 main에 병합하고 운영 사이트에 배포했다. Google, 네이버의 사이트맵 제출과 수집 요청도 완료했다.
- 현재 로컬 작업에는 주부 고객을 위한 화면 개편, `/browse` 검색, `/saved` 저장, 상품 갱신 관련 변경이 진행 중이다. 파일 존재를 운영 반영 완료로 간주하지 않는다.
- 개편 방향은 `CLAUDE.md`와 `docs/design/homemaking-design-system.md`를 따른다. 공개 등급, 순위를 되살리지 않고 사용 조건, 공식 사양, 조회 가격으로 안내한다.
- 신규 가이드 주제는 `docs/homemaking-guide-plan.md`의 5개 기획을 사용한다. 중복 기능이나 별도 디자인 시스템을 만들지 않는다.

## 방문과 구매 흐름

검색 결과 또는 블로그, 영상 → 그 질문에 답하는 가이드 → 구매 전 체크리스트 → 조건에 맞는 상품 비교 → 가격, 옵션 확인 → 판매처에서 구매.

검색, 외부 콘텐츠 링크는 해당 가이드로 연결한다. 추가 탐색이 필요한 사람은 관련 가이드, 검색, 저장 기능으로 이동한다.

## 단계별 실행

| 단계 | 시점 | 실행 내용 | 산출물과 완료 기준 |
| --- | --- | --- | --- |
| 0. 통합 기준 확정 | 착수 시 | 진행 중인 개편과 원격 main의 SEO 변경을 함께 검토한다. 작업 중인 변경을 보존하고 배포할 버전을 정한다. | canonical, robots, sitemap, RSS, 구조화 데이터, Google, 네이버 인증 태그, 문의 정보가 개편에서도 유지된다. 기존 글 URL이 유지된다. |
| 1. 측정 검증 | 1주차 초반 | GA4 수집, 맞춤 정의, 관리자 보고서를 확인한다. 모바일, 데스크톱에서 페이지 이동, 상품 노출, 제휴 클릭, 필터 적용을 검증한다. 검색, 저장 이벤트는 필요한 항목만 보완한다. 제휴사 리포트의 조회 범위와 귀속 기준을 확인한다. | 테스트 행동별 예상 이벤트가 중복 없이 수집된다. 글, 상품, 버튼 위치를 구분할 수 있다. 내부 테스트 유입의 제외, 식별 방법이 정리된다. 채널, 페이지별 기준 보고서를 만든다. |
| 2. 구매 안내 개선 | 1주차 후반 | 가이드 첫 화면에 결론과 적용 조건을 배치한다. 비교 영역에 공식 사양, 구성, 단위당 가격, 조회일, 선택 시 주의점을 표시한다. 모바일 구매 버튼이 현재 선택한 상품, 옵션을 가리키도록 한다. | 대표 가이드 1편으로 검증한다. 320px, 390px 모바일과 데스크톱에서 비교, 저장, 판매처 이동이 가능하다. 버튼이 본문을 가리지 않고 링크의 상품, 옵션이 일치한다. |
| 3. 첫 가이드 묶음 발행 준비 | 2주차 | 아래 5개 주제의 실제 자료를 확보한다. 우선 2편으로 템플릿을 검증하고 나머지 3편에 적용한다. 관련 글을 연결한다. | 자료가 확보된 5편의 원고, 비교표, 제휴 링크, 출처를 준비한다. 사실 검수 완료된 글부터 발행한다. 자료가 부족한 주제는 미확인 상태로 남기고 발행하지 않는다. |
| 4. 유입 실험 | 3주차 | 검색 질문과 글 제목을 맞춘다. 각 가이드에 연결할 네이버 블로그 요약과 인스타 영상 기획을 준비한다. 우선 가이드 2편의 배포 반응을 본다. 외부 링크에 통일된 UTM을 사용한다. | 채널별 게시용 초안, 소재, 연결 URL이 준비된다. 게시된 링크는 해당 가이드로 연결되고 유입 출처를 구분할 수 있다. 자동 댓글, DM은 초기 범위에서 제외한다. |
| 5. 성과 판단과 다음 작업 선정 | 4주차부터 | 채널, 진입 글, 기기별 유입과 클릭 행동을 비교하고 제휴사 주문, 수수료 보고서를 대조한다. 가장 큰 문제 한 가지를 골라 다음 실험을 설계한다. | 유지, 확대, 수정할 주제와 이유를 기록한다. 표본이 부족하면 관찰 기간을 늘리고 승패를 단정하지 않는다. |

## 첫 가이드 5편

| 주제 | 독자의 구매 질문 | 필요한 근거 | 판매처 이동 전 보여줄 정보 |
| --- | --- | --- | --- |
| 키친타월 단가 비교 | 어떤 구성이 내 사용량에 맞는가? | 실제 옵션 가격, 장 수, 크기, 겹 수 | 비교 가능한 규격의 단가와 구성 차이. 단가만으로 품질 우열을 정하지 않는다. |
| 쓰레기통 리필 봉투 | 내 쓰레기통에 맞는 리필인가? | 제조사 호환표와 모델명 | 호환 모델, 규격, 구성 수량 |
| 수납용품 구매 전 치수 | 우리 집 공간에 들어가는가? | 측정 도식과 상품 치수 | 내부 폭, 깊이, 높이와 문, 경첩 간섭 확인표 |
| 밀폐용기 선택 | 담을 음식과 사용 방식에 맞는가? | 제조사 사용 설명, 크기, 용량 | 냉장고 적합성, 세척, 가열 가능 조건 |
| 식기세척기 설치 확인 | 우리 집에 설치할 수 있는가? | 모델별 공식 설치 설명과 서비스 조건 | 공간, 급배수, 전원, 문 열림, 설치비 확인 항목 |

이 목록은 검색량, 구매율을 검증한 순위가 아니다. 착수 시 실제 검색 결과와 Search Console 쿼리, 자료 확보 가능성을 확인해 발행 순서를 조정한다.

## 구매 안내 템플릿

1. **짧은 결론:** 어떤 조건의 사람에게 맞는 선택인지 먼저 말한다.
2. **구매 전 확인:** 3~5개의 치수, 호환, 사용 조건을 제공한다.
3. **비교:** 동일한 구매 목적의 대안을 초기 화면에서 최대 3개로 정리하고 필요한 경우 더 볼 수 있게 한다. 비교 대상이 1개면 단일 제품 안내로 표현한다.
4. **선택 이유와 한계:** 공식 자료와 확인된 사실로 설명한다. 직접 사용하지 않았다면 사용 후기를 작성하지 않는다.
5. **구매 버튼:** 판매처와 동작을 드러내는 ‘쿠팡 가격, 옵션 확인’ 같은 문구를 사용한다. 최저가를 검증하지 않은 경우 최저가 표현을 사용하지 않는다.
6. **추가 탐색:** 관련 가이드와 기존 저장 기능을 연결한다. 구매 버튼 옆의 필수 정보와 제휴 고지를 유지한다.

기존 모바일 하단 버튼과 비교 컴포넌트를 개선한다. 전면 팝업이나 구매 전에 요구하는 회원가입은 추가하지 않는다.

## 측정과 판단 기준

| 지표 | 정의, 출처 | 사용하는 판단 |
| --- | --- | --- |
| 가이드 진입 세션 | GA4에서 해당 가이드가 진입 페이지인 세션. 채널, 글, 기기를 함께 본다. | 어떤 질문과 배포 채널이 방문을 만드는지 판단한다. |
| 제휴 클릭 세션율 | 같은 진입 세션 집단에서 제휴 클릭이 1회 이상 발생한 세션 / 진입 세션. 반복 클릭으로 분자를 늘리지 않는다. | 글이 방문자의 선택을 얼마나 돕는지 보는 대리 지표다. 실제 구매율로 부르지 않는다. |
| 실제 주문, 확정 수수료 | 제휴사 보고서 기준. 주문, 취소, 확정 시점과 귀속 기간을 구분한다. | 실제 수익성과 확대 여부를 판단한다. 초기 미확정 금액은 따로 표시한다. |

- 기존 `view_item_list`, `select_item`, `filter_apply`와 `placement`를 활용한다. 구매 버튼 클릭을 `purchase`로 보내지 않는다.
- 새로 필요한 검색, 저장 이벤트는 구현 여부를 확인한 뒤 최소한으로 추가한다. 개인정보를 이벤트나 UTM에 담지 않는다.
- 외부 유입은 `utm_source`, `utm_medium`, `utm_campaign`, `utm_content` 명명 규칙을 정한다. 사이트 내부 링크에는 유입 출처를 덮어쓰는 UTM을 붙이지 않는다.
- 제휴사의 지원 범위 안에서 채널, 캠페인 식별자를 사용한다. GA 세션과 외부 주문이 1:1로 연결된다고 가정하지 않는다. 연결되지 않는 부분은 집계 수준과 한계를 표시한다.
- 검색은 노출→검색 클릭→가이드 진입, 사이트는 진입→비교 영역 노출→제휴 클릭으로 나누어 본다. 클릭 증가와 함께 실제 주문, 취소, 수수료 방향도 확인한다.
- 초기에는 절대 전환율이나 상승률 목표를 만들지 않는다. 수집 검증 후 확보한 방문 수와 기준 전환율에 따라 실험 크기, 기간을 정한다.
- 낮은 트래픽에서는 여러 A/B 테스트를 동시에 실행하지 않는다. 우선 한 가지 변경의 사용성을 확인하고, 전후 수치에는 유입 구성, 요일, 가격 변경의 영향을 함께 기록한다.

## 다음 행동을 고르는 규칙

- 검색 노출은 있으나 클릭이 적으면 검색 질문과 제목, 설명의 일치를 점검한다.
- 유입은 있으나 비교 영역에 도달하지 않으면 첫 화면의 결론, 정보 순서, 모바일 가독성을 점검한다.
- 비교 영역은 보지만 판매처로 이동하지 않으면 호환 조건, 추천 이유, 가격, 옵션 정보가 충분한지 확인한다.
- 판매처 이동은 있으나 주문 실적이 약하면 상품, 옵션 연결, 재고, 가격과 구매 목적의 일치를 확인한다. 제휴 귀속, 보고 지연 가능성을 먼저 배제한다.
- 자연, 콘텐츠 유입의 수익성이 확인되면 유료 광고의 예산과 손익 기준을 별도로 정한다. 이번 초기 계획에는 광고 지출을 포함하지 않는다.

## 역할과 필요한 접근

- **개발, 측정:** SEO 통합, 템플릿과 이벤트 개선, 보고서 구성, 링크, 모바일 검증.
- **콘텐츠 준비:** 공식 자료 수집, 초안, 비교표, 체크리스트, 블로그, 영상 기획. AI/API 초안은 프로젝트 원칙에 따라 사람이 사실 검수한 뒤 발행한다.
- **운영자:** 필요한 실제 사용 자료 제공, 초안 사실 확인, 외부 채널 계정 운영. 로그인, 인증이 필요한 시점에만 직접 진행한다.
- 착수 시 기존 GA4와 쿠팡 파트너스 보고서 접근을 먼저 확인한다. 블로그, 인스타 연결은 배포 단계에 필요하다. 지금 새 계정 생성이나 로그인은 필요하지 않다.

## 초기 완료 기준

- 진행 중인 개편을 유지하면서 배포된 SEO 설정이 보존된다.
- 모바일에서 질문 확인부터 판매처 이동까지 끊김 없이 진행된다.
- 근거와 실제 링크를 확인한 가이드가 준비되고, 검수 완료된 글만 공개된다.
- 유입 출처, 진입 글, 버튼 위치별 클릭을 구분할 수 있다.
- 실제 주문과 클릭을 분리한 첫 성과 점검이 이루어지며, 다음 개선 한 가지가 정해진다.
