# 처음 등록할 살림 가이드

현재 Grader DB에는 공개된 상품 소개 글 7개가 있다. `comparison` 유형이 7개이고 `guide` 유형은 없다. 글이 비어 보였던 원인은 로컬과 운영 환경의 Supabase 연결 값이 비어 있었기 때문이다.

아래는 신규 글의 기획안이며 발행된 글이나 실제 사용 후기가 아니다. 검색량이나 전환율을 검증한 순위가 아니라, 생활용품 구매에 바로 활용할 수 있는 주제를 우선한 편집 제안이다.

| 순서 | 제목 | 독자가 얻는 것 | 준비할 자료 | 인스타 콘텐츠 연결 |
| --- | --- | --- | --- | --- |
| 1 | 키친타월, 한 롤 가격만 비교하면 안 되는 이유 | 롤 수와 장 수를 반영한 단가 계산, 크기와 겹 수 확인 | 실제 판매 옵션의 가격, 장 수, 한 장 크기, 겹 수 | 단가 계산 예시를 보여주고 `키친타월` 댓글로 전체 비교표 안내 |
| 2 | 쓰레기통 리필 봉투, 호환 모델 확인하는 법 | 본체 모델과 리필 규격을 대조하는 체크리스트 | 제조사 공식 호환표, 본체 및 리필 모델명 | 리필 규격 확인 위치를 보여주고 `리필` 댓글로 체크리스트 안내 |
| 3 | 수납용품 사기 전에 재야 할 치수 | 서랍 안쪽, 경첩, 높이, 문이 열리는 공간을 기록하는 표 | 직접 만든 측정 도식과 실제 상품 외형 치수 | 치수 재는 짧은 영상과 `수납` 댓글 연결 |
| 4 | 밀폐용기 고를 때 확인할 크기와 사용 조건 | 담을 음식과 냉장고 공간에 맞는 크기, 세척과 가열 가능 여부 확인 | 제품별 제조사 사용 설명, 용량과 외형 치수 | 사용 목적별 확인 항목과 `용기` 댓글 연결 |
| 5 | 식기세척기 구매 전 설치 조건 확인하기 | 설치 공간, 급수와 배수, 전원, 문 열림, 설치비 확인표 | 선택 모델의 공식 설치 설명서와 설치 서비스 조건 | 구매 전 확인표 일부와 `설치` 댓글 연결 |

## 글의 구성

1. 구매 전에 헷갈리는 질문에 짧게 답한다.
2. 구매 전에 확인할 항목을 3~5개로 정리한다.
3. 실제 옵션과 공식 사양으로 비교표를 만든다. 가격에는 조회 날짜를 표시한다.
4. 맞는 사용 조건과 추가 확인이 필요한 조건을 구분한다.
5. 확인한 상품 링크, 제휴 고지, 정보 출처를 붙인다.

확인하지 않은 흡수력, 내구성, 건강 효과, 사용 경험은 쓰지 않는다. 장 수와 크기가 다른 키친타월을 단가만으로 우열 평가하지 않는다. 용기의 가열 가능 여부와 가전 설치 조건은 제품별 공식 안내를 따른다. 인스타 댓글 DM 전송은 아직 연결되지 않았으며 실제 발송을 설정하기 전에는 이를 사이트 기능으로 안내하지 않는다.
