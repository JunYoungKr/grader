# 글 가독성

제목과 본문을 빠르게 구분하고 긴 한국어 문단을 편하게 읽도록 글자 위계를 조정한다.

- 제목, 상품명, 가격은 semibold(600)를 사용한다. 본문은 regular(400), 짧은 라벨은 medium(500)을 유지한다.
- 긴 본문과 요약은 17~18px, 행간은 1.85, 최대 폭은 42rem이다. 문단 사이에는 20px 간격을 둔다.
- 본문과 구매 판단에 필요한 설명은 ink, 날짜 등 보조 정보는 muted로 구분한다. 메타 정보는 14px다.
- 토큰 원천은 `src/styles/tokens.css`, Tailwind 매핑은 `tailwind.config.ts`다.
- 글의 본문 구간은 `ArticleSection`으로 렌더링한다. 요약, 상품 카드, 목차, 출처와 관련 글은 기존 공통 컴포넌트에서 관리한다.

이 변경은 현재 원격 화면 구조에 적용한 가독성 개선이다. 로컬에서 진행 중인 전체 화면 개편과 분리하며, 개편을 통합할 때 같은 이름의 토큰과 `ArticleSection`을 사용한다.

검증: 프로덕션 빌드와 타입 검사 통과. 1280px와 320px에서 페이지 가로 넘침이 없고, 제목 굵기 600, 본문 17~18px, 최대 폭 672px 적용을 확인했다.
