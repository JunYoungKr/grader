## 네이버 블로그 초안 1

제목: 매직캔 리필 250과 280, 구매 전에 확인할 번호

리필을 고를 때는 쓰레기통 용량보다 본체 모델 번호를 먼저 확인해 보세요. 공식 카탈로그의 히포 MH250은 250R, MH280은 280R을 적용 리필로 안내합니다. 다른 모델은 해당 모델의 자료를 다시 확인해야 합니다.

본체 모델, 리필 규격, 주문 옵션의 수량을 차례로 맞추면 구매 전 확인하기 편합니다. Grader에 모델 확인 순서와 체크 표를 정리했습니다. 사용 후기나 냄새 차단 시험 결과를 주장하는 글은 아닙니다.

연결 링크: `https://grader.co.kr/magikan-refill-model-check?utm_source=naver_blog&utm_medium=organic_social&utm_campaign=homemaking_launch_202609&utm_content=refill_summary_01`

게시 전 고지: 연결한 Grader 글에 제휴 링크가 포함된다는 사실을 본문 앞부분에 명확히 안내합니다. 실제 게시 계정과 플랫폼 표시 기준도 확인합니다.

## 네이버 블로그 초안 2

제목: 수납함이 선반에 안 들어가는 이유, 뚜껑 포함 치수를 보세요

같은 용량의 수납함도 뚜껑을 포함한 치수는 달라질 수 있습니다. IKEA SAMLA 55L의 공식 안내는 본체 78×56×18cm와 뚜껑 포함 구성 79×57×18cm를 구분합니다.

수납장 안쪽 치수와 입구, 경첩, 꺼내는 동작까지 확인해 보세요. Grader에서 구매 전 기록할 네 가지 항목을 정리했습니다. 이 예시를 모든 수납함의 공통 규격으로 적용하지 않습니다.

연결 링크: `https://grader.co.kr/storage-box-measuring-checklist?utm_source=naver_blog&utm_medium=organic_social&utm_campaign=homemaking_launch_202609&utm_content=storage_summary_01`

## 인스타 영상 기획

| 구간 | 리필 영상 | 수납함 영상 |
| --- | --- | --- |
| 0~3초 | “리필 주문 전, 본체 모델 확인했나요?” | “수납함, 뚜껑까지 재셨나요?” |
| 3~10초 | 직접 촬영한 본체 모델 라벨과 리필 규격을 보여줌 | 직접 촬영한 선반 안쪽과 문 입구 측정 |
| 10~20초 | 모델 번호, 리필 규격, 선택 옵션 순서로 자막 | 본체 치수, 뚜껑 포함 치수, 꺼낼 공간 순서로 자막 |
| 20~25초 | “모델별 자료를 확인하고 주문하세요. 체크 표는 프로필 링크에서.” | “치수 기록표는 프로필 링크에서 확인하세요.” |

실제 촬영 자료가 필요합니다. 사용하지 않은 상품을 직접 사용한 것처럼 연출하거나 외부 리뷰를 자기 경험으로 옮기지 않습니다. 공식 사진은 사용 권한이 확인된 경우에만 활용합니다. 신규 DM 자동 발송은 포함하지 않습니다.

인스타 링크의 `utm_content`는 각각 `refill_reel_01`, `storage_reel_01`을 사용합니다. 클릭 가능한 링크 영역에서 실제 목적지 글이 열리는지 확인합니다.

## 운영 기록과 다음 판단

게시 날짜와 계정, 최종 URL, 소재 버전을 기록합니다. GA4에서는 같은 기간의 진입 페이지와 세션 소스/매체, 기기별 세션, `select_item` 주요 이벤트의 세션율을 확인합니다. 일반 클릭 이벤트 `click`과 합산하지 않습니다.

주문과 수수료는 쿠팡 파트너스 보고서의 기간과 귀속 기준을 따로 기록합니다. 표본이 작으면 승자나 상승률을 발표하지 않고, 실제로 들어오는 질문과 페이지 내 이탈 단계를 다음 콘텐츠 개선에 사용합니다.
