# 첫 살림 가이드 검수 묶음

작성일: 2026-09-27. 상태: 발행 전 초안. 운영 DB에 등록하지 않았습니다.

아래 원고는 직접 사용 후기가 아닌 구매 전 확인 안내입니다. 공식 자료에서 확인한 사실과 편집 제안을 구분했습니다. 조회 가격은 옵션이 확정되지 않아 비교표에 넣지 않았습니다. 사람의 사실 검수, 연결할 실제 상품 옵션 확인이 끝난 글부터 발행합니다.

## 1. 키친타월 가격 비교, 롤 수보다 먼저 볼 세 가지

예정 경로: `/kitchen-towel-unit-price`

검색 질문: 키친타월 100매당 가격, 키친타월 몇 롤이 저렴한가.

### 원고

묶음 가격만 보고 고르면 실제로 받는 양을 놓치기 쉽습니다. 같은 크기와 겹 수의 상품끼리 전체 장 수를 맞춘 다음, 100매당 가격을 계산하세요. 크기가 다른 상품은 면적도 함께 비교해야 합니다.

구매 전 상품 옵션에서 한 롤의 장 수, 전체 롤 수, 한 장의 가로와 세로, 겹 수를 기록합니다. 배송비나 누구나 받을 수 없는 회원 할인도 별도로 확인합니다. 계산에 쓴 가격은 확인 날짜와 함께 남깁니다.

100매당 가격은 비교에 포함한 총금액을 전체 장 수로 나눈 뒤 100을 곱합니다. 전체 장 수는 한 롤의 장 수에 실제 받는 롤 수를 곱한 값입니다. 낱장 크기가 다르면 전체 면적을 계산해 같은 면적당 비용도 확인할 수 있습니다. 겹 수는 펼쳐진 종이 면적에 다시 곱하지 않습니다.

예를 들어 150매 6롤이 6,000원이라는 가상의 구성은 총 900매이며 100매당 약 667원입니다. 이 숫자는 계산 설명용이며 실제 상품 가격이 아닙니다.

계산한 단가가 낮다고 흡수력이나 내구성이 더 좋은 것은 아닙니다. 두 성능은 별도 시험이나 사용 근거가 있어야 비교할 수 있습니다. 먼저 주로 닦는 용도와 사용량을 정하고, 보관할 공간까지 확인하세요.

### 옵션 검수표

| 후보 | 확인된 정보 | 추가 확인 | 현재 결론 |
| --- | --- | --- | --- |
| 코멧 깨끗한 천연펄프 2겹 키친타올 150매 | 운영 상품 목록에 상품 ID 169280610 존재 | 연결 옵션의 롤 수, 한 장 크기, 배송비 | 단가 계산 보류 |
| 크리넥스 안심 3겹 키친타올 | 운영 상품 목록에 상품 ID 7134558328 존재 | 연결 옵션의 장 수와 롤 수, 한 장 크기 | 단가 계산 보류 |

운영 목록은 상품 발견 근거입니다. 상품명에 없는 옵션이나 규격을 추정하지 않습니다. 서로 겹 수가 달라 단가로 우열을 매기지 않습니다. 검수자는 실제 링크의 옵션을 확인해 같은 규격의 비교 대상을 추가하거나, 서로 다른 규격의 선택 안내로 발행합니다.

## 2. 매직캔 리필, 용량보다 모델 번호부터 확인하세요

예정 경로: `/magikan-refill-model-check`

검색 질문: 매직캔 250 280 차이, 우리 쓰레기통 리필 찾기.

### 원고

리필 봉투는 쓰레기통에 표시된 모델 번호를 기준으로 고르세요. 집에서 쓰는 제품의 용량이 비슷해도 리필 규격은 다를 수 있습니다. 본체 라벨을 확인한 뒤 제조사 자료의 적용 리필 번호와 주문 옵션을 차례로 맞춥니다.

매직캔 공식 2024 카탈로그에서 히포 MH250은 250R, MH280은 280R을 적용 리필로 안내합니다. 이 예시는 해당 모델에 한정되며 다른 제품이나 후속 모델의 호환을 뜻하지 않습니다. [매직캔 공식 카탈로그, PDF 7~8쪽](https://company.magikan.co.kr/cms/uploads/MAGIKAN_CATALOGUE_240124_VF_e1c968c740.pdf)

제품 바닥이나 본체의 모델 번호를 사진으로 남기고, 구매하려는 봉투의 규격 번호를 비교하세요. 판매 페이지의 대표 사진만 보지 말고 선택된 옵션을 확인해야 합니다. 이미 사용 중인 리필 포장도 규격 확인에 도움이 됩니다.

같은 규격 안에서도 롤 수, 길이, 색상, 향 유무가 다를 수 있습니다. 호환을 먼저 확인하고 구성과 가격을 비교합니다. 정확한 모델을 찾지 못했으면 제조사에 모델 사진으로 확인한 뒤 주문하세요.

### 확인 표

| 본체 모델 | 공식 카탈로그의 리필 | 발행 전 확인 |
| --- | --- | --- |
| MH250 | 250R | 최신 판매 옵션과 모델명 일치 |
| MH280 | 280R | 최신 판매 옵션과 모델명 일치 |

운영 목록의 상품 ID 8366355412는 280 리필 후보입니다. 연결 옵션의 수량과 규격을 확인하기 전에는 위 표의 구매 버튼으로 연결하지 않습니다. 호환품에 대한 제조사 보증이나 사용 성능을 임의로 붙이지 않습니다.

## 3. 수납함 사기 전, 안쪽 치수와 뚜껑을 함께 재세요

예정 경로: `/storage-box-measuring-checklist`

검색 질문: 수납함 사이즈 재는 법, 선반 수납함 안 들어감.

### 원고

수납함을 둘 공간의 안쪽 폭, 깊이, 높이를 먼저 재세요. 수납장 전체 크기와 실제로 쓸 수 있는 공간은 다를 수 있습니다. 경첩과 선반 받침, 문이 열리는 범위도 함께 확인합니다.

수납함을 고를 때는 뚜껑과 손잡이를 포함한 완성 상태 치수를 사용하세요. IKEA의 SAMLA 55L 예시는 본체가 78×56×18cm, 뚜껑 포함 구성이 79×57×18cm로 안내됩니다. 이 차이는 해당 구성의 예시이며 모든 수납함에 같은 여유를 적용하는 기준은 아닙니다. [SAMLA 본체](https://www.ikea.com/kr/ko/p/samla-box-transparent-30180943/), [뚜껑 포함 구성](https://www.ikea.com/kr/ko/p/samla-box-with-lid-transparent-s69440817/)

선반 입구를 통과할 수 있는지, 넣은 뒤 손을 넣어 꺼낼 수 있는지 따로 확인하세요. 뚜껑을 선반 안에서 열 것인지, 통째로 꺼낼 것인지도 정해두면 크기를 고르기 쉽습니다. 외부 치수만으로 내부에 담을 물건의 적합성을 단정하지 않습니다.

### 독자용 기록표

| 확인할 곳 | 우리 집 기록 |
| --- | --- |
| 놓을 공간의 내부 폭과 깊이, 높이 | 직접 측정 |
| 문과 경첩을 지난 입구의 가장 좁은 부분 | 직접 측정 |
| 뚜껑과 손잡이를 포함한 상품 크기 | 공식 치수 확인 |
| 꺼내고 뚜껑을 여는 데 필요한 공간 | 실제 동작 확인 |

발행 전 확인: 측정 도식 검수, 실제 연결 상품의 완성 치수와 상세 도면 확보. 출처의 IKEA 링크는 공식 참고 링크이며 제휴 링크가 아닙니다.

## 4. 밀폐용기 고르기, 용량과 사용 조건을 따로 보세요

예정 경로: `/food-container-use-checklist`

검색 질문: 밀폐용기 전자레인지 뚜껑, 냉장고 용기 사이즈.

### 원고

밀폐용기는 담을 양, 넣을 공간, 데우고 씻는 방법을 함께 확인해야 합니다. 같은 용량이어도 가로와 높이가 다를 수 있으므로 냉장고 선반이나 도시락 가방에 넣을 때는 외부 치수를 비교하세요.

몸체와 뚜껑의 사용 조건은 따로 확인합니다. 락앤락 공식 고객 안내도 뚜껑 잠금 방식과 스팀홀 유무에 따라 전자레인지 사용법을 구분합니다. 따라서 제품의 재질 이름만 보고 뚜껑까지 같은 방식으로 가열해도 된다고 판단하면 안 됩니다. [락앤락 공식 고객 안내](https://locknlock.com/kor/util/customer/)

구매하려는 모델의 설명에서 전자레인지, 식기세척기, 냉동 보관 가능 여부를 각각 확인하세요. 같은 브랜드의 다른 제품 안내를 그대로 적용하지 않습니다. 특히 온도나 가열 시간을 표에 넣을 때는 정확히 같은 모델의 사용 설명서를 근거로 삼습니다.

패킹 분리 여부와 교체품 판매 여부도 확인할 항목입니다. 자주 여닫는 용도인지, 한 번 담아 보관하는 용도인지에 따라 세척 동선과 뚜껑 구조를 비교해 보세요. 밀폐력이나 냄새 배임 정도는 직접 시험하지 않았다면 우열을 말하지 않습니다.

### 모델별 검수표

| 기록할 정보 | 근거 |
| --- | --- |
| 모델 번호, 용량, 외부 치수 | 해당 모델 공식 상세 설명 |
| 몸체와 뚜껑의 가열 조건 | 해당 모델 사용 설명서 |
| 세척과 냉동 보관 조건 | 해당 모델 사용 설명서 |
| 패킹 분리와 교체품 여부 | 제조사 안내 |

발행 전 확인: 2~3개 구체적 모델 선정, 모델별 설명서와 판매 옵션 대조. 확인되지 않은 온도와 시간은 원고에 추가하지 않습니다.

## 5. 식기세척기 주문 전, 설치 공간부터 확인하세요

예정 경로: `/dishwasher-installation-checklist`

검색 질문: 식기세척기 설치 가능 확인, 식기세척기 싱크대 치수.

### 원고

식기세척기는 제품 외형 크기만으로 설치 가능 여부를 판단하기 어렵습니다. 구매하려는 모델의 설치 공간과 문 열림 조건을 확인한 뒤, 설치 상담에서 주방 상태를 함께 점검하세요.

LG전자 2026년 1월 B2B 카탈로그는 DEE6BGE의 제품 크기를 598×815×567mm, 설치 공간을 600×815×600mm로 구분합니다. 치수 순서는 폭, 높이, 깊이입니다. 이 값은 해당 모델의 안내 예시이며 다른 모델에 그대로 적용하지 않습니다. [LG전자 공식 카탈로그, PDF 83쪽](https://www.lge.co.kr/kr/ebook/2026/january/b2b/catImage/628/20260102_b2b_catalogue.pdf)

설치할 자리의 폭과 높이, 깊이를 적고 정면과 하부장 사진을 준비하세요. 급수와 배수 연결 위치, 전원 위치, 문을 열었을 때 앞쪽 공간도 상담 항목으로 남깁니다. 치수가 맞아도 배관이나 가구 구조에 따라 추가 작업이 필요할 수 있습니다.

주문 전 판매처에 기본 설치에 포함되는 작업과 추가 비용을 구분해 확인하세요. 가구 공사, 기존 제품 처리, 현장 설치 불가 시 처리 조건도 계약할 판매처 기준으로 확인해야 합니다. 전기나 배관을 직접 개조하는 안내는 이 글에 포함하지 않습니다.

### 상담 준비표

| 항목 | 준비할 정보 |
| --- | --- |
| 구매할 제품 | 정확한 모델 번호 |
| 설치 자리 | 안쪽 폭, 높이, 깊이와 사진 |
| 연결 조건 | 급수, 배수, 전원 위치 |
| 사용 공간 | 문 개폐와 이동 동선 |
| 비용 | 기본 설치 범위와 추가 작업 견적 |

발행 전 확인: 판매할 실제 모델의 최신 설치 문서, 판매처 설치 범위, 옵션과 제휴 링크. 상담 전 설치 가능 확정이나 공사비 금액을 보장하지 않습니다.
