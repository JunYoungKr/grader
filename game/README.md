# Centipede Express — 코어 물리 프로토타입 (v0.1)

기획서(`Centipede Express v0.1`)의 **3.1 "한 몸, 여러 뇌" 조종 구조**가
실제로 재밌는지 확인하기 위한 브라우저 그레이박스입니다.
기획서 10.2가 지목한 최대 리스크("연결된 지네를 여럿이 조종하는 게 웃긴가")를
Unity 없이 가장 빠르게 눈으로 검증하는 것이 목적입니다.

> 웹 프로토타입 → 코어 물리만 → 로컬 멀티 + 봇 마디, 이 세 방향으로 구현했습니다.

## 실행

빌드/설치 불필요. 정적 파일이라 브라우저로 바로 엽니다.

```bash
# 방법 1: 파일 직접 열기
open game/index.html            # macOS
xdg-open game/index.html        # Linux
start game/index.html           # Windows

# 방법 2: 로컬 서버(권장 — 일부 브라우저 file:// 제약 회피)
cd game && python3 -m http.server 8080
# → http://localhost:8080
```

물리엔진 [Matter.js](https://brm.io/matter-js/) 0.20.0을 `vendor/matter.min.js`로
**로컬 번들**했기에 오프라인에서도 동작합니다(CDN 불필요).

## 조작

| 동작 | P1 | P2 (P로 켜기) |
|---|---|---|
| 좌/우 이동 | `A` `D` | `←` `→` |
| 점프 | `W` / `Space` | `↑` |
| 그립(앵커·브레이크) | `S` | `↓` |

기타: `1`~`8` P1이 조종할 마디 · `[` `]` P2 마디 · `+`/`-` 지네 길이(2~8) ·
`R` 리셋 · `C` 화물 재배치 · `B` 전원 자동주행(데모) · `X` 자가충돌 토글(카오스) · `H` 도움말

**혼자라면**: 한 마디(기본은 머리)를 조종하면 나머지는 봇 마디가 협력 추종합니다.
`1`~`8`로 조종 마디를 바꿔가며 점프·그립 타이밍을 맞춰 계단·낭떠러지를 넘어보세요.
**둘이라면**: `P`로 P2를 켜고 서로 다른 마디를 잡으면 — 방향이 어긋나는 순간 지네가 꼬입니다.

## 지금 구현된 것 (코어 물리만)

- **연결된 N개 마디**: 관절(Constraint)로 이어져 서로를 물리적으로 당김. 자가충돌로 몸이 꼬임.
- **마디별 독립 조작**: 마디마다 독립된 힘 적용 = "여러 뇌".
- **봇 마디**: 가장 가까운 사람 마디의 입력을 약하게 협력 추종(기획서 "단순 추종 AI"). 계단·정면 장애물에서 자동 점프.
- **공용 액션**: 점프, 그립(마디를 순간 고정 → 앵커/브레이크).
- **시너지 게이지**: 마디들의 수평 이동 방향이 정렬될수록 이동 힘 증가(기획서 "같은 방향 → 빨라짐").
- **화물 물리**: 등 위에 얹힌 상자가 기울기·충격에 미끄러져 떨어짐. 등에 남은 화물 수 실시간 표기.
- **지형**: 시작 바닥 → 계단 → 낭떠러지 → 중간 단 → 도착 지점(GOAL 깃발).
- **카메라**: 조종 중인 마디를 따라감.

## 아직 없는 것 (다음 단계)

- 배달 평가 루프(별점·시간·파손율·팁)와 보수/언락 — 기획서 3.3
- 특수 마디 6종(스프링/흡착/부스터/집게/풍선/발광) — 기획서 5장
- 화물 6종의 개별 특성(유리병/수프/애벌레/얼음/초대형) — 지금은 일반 상자 1종
- 네트워킹(host-authoritative + Steam Relay) — 현재는 로컬 단일 머신
- 협동 테크닉(웨이브 대시/다리 놓기/투석기 등) 전용 입력 — 지금은 물리로 창발만
- 아트/사운드 — 지금은 그레이박스 색상

## 튜닝

느낌은 `centipede.js` 상단 `CFG` 객체의 숫자로 조절합니다:
`moveForce`(이동 힘), `jumpV`(점프), `jointStiffness`(관절 강성),
`botFollow`(봇 협력 강도), `synergyMin/MaxBonus`(정렬 보너스), `cargoCount`(화물 수) 등.

## 검증 메모

Playwright(Chromium)로 로드 시 JS 에러 0, 자동주행이 전 지형을 통과해 GOAL 도달,
사람 조작(이동+점프)으로도 완주, 화물이 급기동 시 등에서 이탈함을 확인했습니다.
